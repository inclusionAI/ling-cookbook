# 下一轮验证设计

现有 v2 继续使用，默认思考开启。本文是下一轮实验的执行约束，不是新结果或训练启动记录。

## 先解决输入与事实边界

真实牌桌不给玩家隐藏身份，而历史离线输入给出了身份。下一轮先在验证集做三组配对诊断：原始真实身份、现有应用的平民假设、明确身份未知。只改变身份字段，固定词语、历史、座位、存活名单、权重和解码预算。该诊断只能估计输入条件变化，不能称为新的独立验证或已提高实战能力。

新基准必须区分玩家可见输入与裁判事实。输入只含自己的词、座位、存活名单、合法候选和当时已公开的发言；真实身份、其他玩家词语、胜负及未来回合不得进入输入。平民命中率只在裁判事后确认的平民子集中计算；不把卧底投票的规则式标签当成唯一最优决策。

## 数据与拆分

- 以完整游戏为最小拆分单位，记录稳定 game_id；同局所有轮次和座位置换归入同一拆分。
- 确认性留出集使用未参与训练、诊断或模型选择的词对与游戏；现有 16 个平民验证状态仅作开发诊断。
- 覆盖首轮、淘汰后、后期少人和 PK；合法候选取事实层名单，不能从对话猜测存活状态。
- 保留发言缺乏区分信息的状态并单独报告，不能只筛选属性 oracle 能答对的状态作为总体基准。
- 记录输入来源、去重键、拆分清单和内容哈希，先通过事实泄漏与合法动作审计再运行模型。

## 比较与统计

比较底座、现有 v2、合法随机动作基线；如果之后训练新候选，先固定相同数据与预算的重复训练对照。每条状态的原编号和重编号使用同一解码种子，重编号同步更新本人、存活名单、历史和候选。普通评测 `--sample-seeds` 采用命令行种子加原始样本行偏移，记录实际种子，禁止让样本元数据静默覆盖它。

分别报告原始输出与清洗后动作的格式合法率、自票/出局票/越界票、弃权率、平民真实命中、非弃权重编号一致性，以及发言泄词和长度。清洗后合法不能替代原始模型指标。

多个解码种子是同一游戏上的重复测量；按游戏聚类重采样，不把回合、重编号或解码种子当独立样本。若只有合成状态、没有真实游戏关联，按源状态聚类并明确范围。独立训练种子与解码种子分开记录。

## 训练启动与采用

先完成身份条件配对诊断和新数据审计，确认错误主要来自可学习的信息/策略缺口，再固定训练目标。当前没有这项证据，因此不追加同配方训练。

候选采用门槛必须在查看新确认集输出前确定：主决策指标、按游戏统计的不确定区间、可接受的发言/合法性退化范围、训练/推理预算和停止规则。门槛与样本规模要根据开发数据和实际资源明确量化，不能在看到候选结果后补定。

只有开发诊断通过并冻结候选后，才运行一次未接触确认集。确认集不能再用于筛选下一版；未通过则保留 v2。脚本控制席的接入验收不能替代多模型决策质量或胜率基准。
